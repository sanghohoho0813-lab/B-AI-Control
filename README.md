# B&AI Control

비앤테일러샵과 AI 소프트웨어 법인의 **매출 · 운영 · 프로젝트 · 자금 · 주요 일정**을
하나의 계정에서 관리하는 통합 경영 OS (MVP 프론트엔드).

별도의 백엔드 없이 현실적인 mock data로 동작하며, Vercel에 그대로 배포할 수 있습니다.

## 기술 구성

| 항목 | 내용 |
| --- | --- |
| 프레임워크 | Next.js 16 (App Router) |
| 언어 | TypeScript |
| 스타일 | Tailwind CSS v4 |
| 컴포넌트 | shadcn/ui 방식 (Radix UI 기반 자체 구성) |
| 아이콘 | Lucide Icons |
| 차트 | Recharts |
| 데이터 | `src/lib/data.ts` mock data (백엔드 없음) |

## 실행

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 프로덕션 빌드
npm start
```

## 설계 기준

- **두 법인의 데이터를 절대 섞지 않는다.** 비앤테일러샵은 버건디, AI 법인은 딥 네이비로
  카드·차트·배지·진행바 색을 통일했고, 합산 수치를 보여줄 때도 항상 회사별 내역을 함께 표시합니다.
- **Company Switcher가 화면 전체를 제어합니다.** 헤더 · 사이드바 · 자금 관리 탭 · 회사 전환 페이지에서
  선택한 회사가 전역 상태(`src/components/app-store.tsx`)로 공유되어 KPI, 차트 시리즈, 목록,
  메모까지 함께 필터링됩니다.
- **모바일은 완전히 별도의 앱입니다.** 반응형 축소판이 아니라 대표자용 경영 브리핑 앱으로
  따로 설계했습니다. 자세한 내용은 아래 “모바일 앱” 항목을 참고하세요.

## 모바일 앱 (390 × 844 기준)

`src/app/(app)/layout.tsx`는 `matchMedia`로 화면을 판별해 **데스크톱 셸과 모바일 셸 중 한쪽만
렌더링**합니다. 따라서 모바일에서는 데스크톱 사이드바·헤더·데이터 테이블·Recharts 차트가
DOM에 아예 존재하지 않습니다. 모바일 화면은 데스크톱 페이지를 재사용하지 않고
`src/components/mobile/`에 따로 작성된 화면 레지스트리를 사용합니다.

**구조**

| 영역 | 내용 |
| --- | --- |
| 헤더 (56px) | 로고 · 알림 · 대표자 프로필. 버튼은 2개뿐 |
| 회사 전환 | 헤더 바로 아래 3분할 탭(전체 · 비앤테일러샵 · AI 법인) **한 곳에만** 존재 |
| 본문 | 요약 중심. 카드를 누르면 상세 화면으로 이동 |
| 하단 내비 | 홈 · 업무 · 일정 · 자금 · 더보기 고정. 선택 탭만 회사 색으로 강조 |

**첫 화면 순서**

1. 인사말 — “대표자님, 오늘 확인할 업무가 6건 있습니다.” + 날짜
2. 오늘의 핵심 요약 — 오늘 매출 · 가용자금 · 긴급업무 · 오늘 일정 (2열 4카드)
3. 긴급 확인 업무 — 최대 4건 (회사 배지 · 제목 · 상태 · 시간)
4. 회사별 요약 — 회사당 카드 1개
5. 오늘 일정 — 타임라인 3~4건
6. 대표자 확인 필요 — 건수만 표시

**타이포그래피**

본문 14~15px, 지표 숫자 22~28px, 화면 제목 23px 기준으로 데스크톱보다 크게 잡았습니다.
목록 제목은 말줄임 대신 `break-keep` 줄바꿈을 사용해 어떤 해상도에서도 글자가 잘리지 않습니다.

**표현 규칙**

- 첫 화면은 “오늘의 실행” 4개 액션 타일(긴급 업무 · 승인 대기 · 납품 예정 · 오늘 일정)로 시작하며,
  각 타일과 긴급 업무 목록에는 바로 누를 수 있는 실행 버튼이 붙습니다.
- 표 대신 카드 리스트 · 타임라인 · 진행률 · 상태 배지를 사용합니다.
- 추이는 Recharts를 쓰지 않고 모바일 전용 미니 막대(`MTrend`)로 별도 구성합니다.
- 한 화면의 KPI 카드는 4개를 넘지 않습니다.
- 회사 구분은 좌측 컬러 바와 배지로만 표시합니다.

## 동작하는 인터랙션

- Company Switcher (헤더 · 사이드바 · 자금 관리 탭 · 회사 전환 페이지)
- 사이드바 메뉴 이동 (데스크톱) / 하단 탭 · 더보기 이동 (모바일)
- 날짜·조회 기간 필터, 차트 기간 변경 (6개월 ↔ 12개월)
- KPI 카드 클릭 → 상세 화면 이동
- 알림 패널 열기 · 개별/전체 읽음 처리
- 통합 검색 (고객 · 주문 · 원단 · 프로젝트 · 메뉴)
- 프로젝트 상세 모달 · 주문 상세 모달 · 고객 상세 모달 · 원단 발주 모달 · 보고서 모달
- 자금 집행 등록 모달 (등록 시 집행 내역에 `승인 대기`로 추가)
- 대표자 메모 추가
- 주문 단계 / 사업화 단계 / 고객 등급 / 원단 상태 / 알림 등급 / 일정 유형 필터
- 일정 완료 체크
- 모바일 : 하단 탭 전환 · 회사 전환 탭 · 뒤로 가기 · 승인/보류 처리 · 필터 칩

## 디렉터리

```
src/
├── app/
│   ├── (app)/            # 사이드바 + 헤더가 적용되는 모든 화면
│   ├── globals.css       # 디자인 토큰 (컬러 · 그림자 · 반경)
│   └── layout.tsx
├── components/
│   ├── shell/            # (데스크톱) 사이드바 · 헤더 · 회사 전환 · 알림 · 검색
│   ├── mobile/           # (모바일) 독립 브리핑 앱
│   │   ├── mobile-app.tsx    # 셸 · 화면 레지스트리 · 하단 내비
│   │   ├── ui.tsx            # 모바일 전용 프리미티브
│   │   ├── nav-context.tsx   # 화면 이동 · 뒤로가기
│   │   └── screens/          # 홈 · 탭 화면 · 상세 화면
│   ├── ui/               # Button · Card · Dialog · Sheet · Tabs · Table · Badge
│   ├── charts.tsx        # Recharts 래퍼
│   ├── modals.tsx        # 주문 · 프로젝트 · 자금 집행 모달
│   ├── page-kit.tsx      # PageHeader · KpiCard · StageFlow 등
│   └── app-store.tsx     # 회사 선택 · 기간 · 알림 · 메모 · 집행 내역 상태
└── lib/
    ├── data.ts           # mock data (전부 한국어)
    ├── types.ts
    ├── nav.ts
    └── utils.ts          # 통화 포맷 · 회사별 컬러 토큰 · 상태 배지 스타일
```

## 참고

모든 수치와 고객·프로젝트 정보는 데모용 mock data입니다.
